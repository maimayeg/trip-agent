Week 1 — Build the agent
Mon · Day 1 Repo setup + project skeleton
Setup ▼
GitHub: github.com → New repo → Settings → Collaborators. Use python -m venv .venv and commit a README.md skeleton on day one.
Tue · Day 2 Weather tool
Setup ▼
Free options: OpenWeatherMap (free tier, 60 calls/min) · Open-Meteo (no key needed, fully free). Geocode the city to lat/lon first, then call the forecast endpoint.
Wed · Day 3 Geocoding tool
Setup ▼
Nominatim (OSM) — free, no key needed. Or Google Geocoding API for higher reliability. Chain this tool's output into the weather tool.
Thu · Day 4 Public holidays tool
Setup ▼
Nager.Date API — completely free, no auth, 100+ countries. Endpoint: GET /api/v3/PublicHolidays/{year}/{countryCode}. Filter results to the user's travel window.
Fri · Day 5 Wire up the ReAct agent
Setup ▼
LangChain docs: AgentExecutor guide. Use ChatAnthropic or ChatOpenAI. Set verbose=True to watch tool calls in the terminal.
Week 2 — Observability
Mon · Day 6 Pick an observability platform
Observability ▼
LangSmith (first-party, easiest LangChain integration) · Langfuse (open-source, self-hostable) · Helicone (proxy-based, lightweight). LangSmith has a generous free tier and zero extra code.
Tue–Wed · Day 7–8 Instrument traces + add metadata
Observability ▼
LangSmith auto-traces everything once env vars are set — no code changes. See docs.smith.langchain.com/tracing.
Thu–Fri · Day 9–10 Review traces + structured logging
Observability ▼
Look for: unnecessary tool re-calls, hallucinated city names, or missing holiday data. These become your first eval cases next week.
Week 3 — Evals
Mon–Tue · Day 11–12 Build an eval dataset
Evals ▼
LangSmith: Datasets → New Dataset → Upload CSV. Columns: input, expected_output. For LLM-as-judge you only need the input column.
Wed–Thu · Day 13–14 LLM-as-judge evaluator
Evals ▼
Use langsmith.evaluate() with a custom RunEvaluator. See LangSmith eval docs. Alternatively try RAGAS for off-the-shelf metrics.
Fri · Day 15 Iterate on low-scoring cases
Evals ▼
Common fixes: add a system prompt with today's date so the agent reasons about "next week" correctly; tighten the geocoding fallback for ambiguous city names.
Week 4 — Deployment
Mon–Fri · Day 16–20 Wrap, deploy, and document
Deploy ▼
LangServe gives you a /invoke REST endpoint in ~5 lines. Deploy to Render or Railway for a free public URL. Add a Dockerfile and a README with setup instructions.
